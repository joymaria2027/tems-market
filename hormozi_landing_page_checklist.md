# Alex Hormozi Landing Page Checklist

> **The Razor:** If it doesn't increase opt-in percentage of qualified leads, **cut it.**

---

## 1. Headline
- [ ] Stops the visitor in their tracks immediately
- [ ] Promises a **clear, specific outcome** (not vague or clever)
- [ ] Works as a standalone statement — no context needed

## 2. Sub-headline
- [ ] Adds context and clarification to the headline
- [ ] Functions like a "thumbnail to headline" relationship (think YouTube)
- [ ] Does NOT repeat the headline — it **expands** it

## 3. Hero Image
- [ ] Adds **proof** to the headline + sub-headline combo
- [ ] Shows either:
  - [ ] The **thing** the visitor is going to get, OR
  - [ ] The **outcome** they want to experience — visually
- [ ] Is NOT a generic stock photo or decorative filler

## 4. Call-to-Action (CTA)
- [ ] States **what they're going to get**
- [ ] States **how they're going to get it**
- [ ] Contains **nothing else** — no fluff, no extras

## 5. Form / Opt-in Fields
- [ ] Collects as little info as needed to get a **qualified** lead
- [ ] Leans toward **more fields** if it filters for better customers (quality > quantity)
- [ ] If more than 5 fields → **broken into multiple steps**

## 6. Lead Magnet Description *(Optional)*
- [ ] One-line description only
- [ ] Answers the single question: *"Why should I give you my email?"*
- [ ] Provides **justification**, not a sales pitch

## 7. Below-the-Fold Bullets *(If needed)*
- [ ] Maximum of **3 bullets**
- [ ] Each bullet addresses a **major objection**
- [ ] Ordered from **most common → least common** objection

## 8. Social Proof *(Only if necessary)*
- [ ] Used only when needed (complex offer, high-ticket, unfamiliar brand)
- [ ] Placed **underneath** the main content, not competing with CTA
- [ ] Kept minimal — don't let it dilute the primary action

## 9. Visual Design & Layout
- [ ] Page is mostly **blank/clean** — all attention directed to the CTA
- [ ] No unnecessary elements distracting from the single action
- [ ] Shorter page = higher conversion (resist the urge to add more)

## 10. Technical & Mobile Optimization
- [ ] **Mobile-optimized** — tested on actual devices
- [ ] **Fast loading** — all images compressed
- [ ] Page loads quickly on slow connections

## 11. Legal Compliance
- [ ] Privacy policy link present
- [ ] Terms of service link present
- [ ] Any required disclaimers included
- [ ] GDPR/consent checkboxes if applicable

---

## The Decision Framework

For **every element** on the page, ask:

> *"Does this increase the opt-in percentage of qualified leads?"*

| Answer | Action |
|--------|--------|
| **Yes** | Keep it |
| **No** | Cut it |
| **Not sure** | Test it, then decide |

---

> [!TIP]
> **Key mindset shift from the transcript:** Hormozi evolved from optimizing for *more opt-ins* to optimizing for *more customers*. More form fields can mean fewer leads but **better** leads. Optimize for downstream revenue, not vanity metrics.
